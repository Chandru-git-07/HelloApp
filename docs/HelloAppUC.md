# HelloApp Use Cases

---

## UC1 - Basic Greeting
**Description:**  
Print a simple greeting message in the console.

**Input:**  
None

**Output:**  
Hello World

---

## UC2 - Greet User via Command-Line Argument
**Description:**  
Accept a single name as a command-line argument and display a greeting.

**Input:**  
Program argument (name)

**Output:**  
Hello, <name>

---

## UC3 - Default Greeting (Optional Argument Handling)
**Description:**  
If no command-line argument is provided, display a default greeting.

**Input:**  
Optional argument

**Output:**  
Hello, Guest (if no input)

---

## UC4 - Multiple Names via Command-Line
**Description:**  
Accept multiple names as command-line arguments and greet each.

**Input:**  
Multiple names

**Output:**  
Hello, Alice  
Hello, Bob

---

## UC5 - Read Single Name from Standard Input
**Description:**  
Prompt user to enter a name via console input.

**Input:**  
User input

**Output:**  
Hello, <name>

---

## UC6 - Read Multiple Names from Standard Input
**Description:**  
Accept multiple names from user input and process them.

**Input:**  
Multiple user inputs

**Output:**  
Greetings for all names

---

## UC7 - Store Names in Memory
**Description:**  
Store entered names in a data structure and display them when requested.

**Input:**  
Names list

**Output:**  
Stored names list

---

## UC8 - Remove Stored Names
**Description:**  
Allow deletion of a specific name from stored data.

**Input:**  
Name to remove

**Output:**  
Updated list

---

## UC9 - Modular Input Processing
**Description:**  
Refactor input handling into separate reusable functions.

**Input:**  
Any input source

**Output:**  
Processed input via methods

---

## UC10 - Separate Name Management Class
**Description:**  
Move name storage and operations into a dedicated class.

**Input:**  
Names

**Output:**  
Managed via class methods

---

## UC11 - Persistent Storage
**Description:**  
Save names to a file and reload them when the program starts.

**Input:**  
File storage

**Output:**  
Persistent data across runs

---

## UC12 - Banner Style Output
**Description:**  
Display greeting messages in a formatted banner style.

**Input:**  
Name

**Output:**  
Styled greeting output
